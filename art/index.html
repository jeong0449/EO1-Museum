Generative Art Gallery

Small programs that create continuously evolving artwork for the EO1 display.

These generative artworks were created for the EO1-Museum project by Haeyoung Jeong in collaboration with ChatGPT. The concepts, visual direction, testing, and curation were developed interactively, while ChatGPT assisted with the HTML5 Canvas and JavaScript implementation. Each work runs directly in the browser and is designed for the EO1's 1080 × 1920 portrait display.
